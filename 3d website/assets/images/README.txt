This folder is intentionally empty by default.

The site does not require any files here — every product visual is generated
procedurally (inline SVG + a live Three.js 3D model), so there are no broken
image links out of the box.

If you generate AI product photography later, drop PNG files here using these
exact names and they will automatically replace the procedural visuals
(see the "Visual assets" section of the project README.md for suggested
prompts):

  hero-watch.png
  watch-noir.png
  watch-aurelis.png
  watch-meridian.png
  watch-eclipse.png
  craftsmanship.png
  editorial-watch.png
